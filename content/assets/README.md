# Asset Metadata

All publishable assets must have one metadata file under this directory tree.

Current convention:

```text
content/assets/<asset_family>/<market_slug>/<asset_slug>.json
```

Authoritative rules live in:

- `docs/architecture/asset-conventions.md`
- `contracts/publishing/asset-metadata.schema.json`

Example metadata files are included for:

- proof assets
- campaign assets
- client briefing assets
